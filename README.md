# Doctor and Patient Portal

## Introduction
This project is a web-based system designed to manage doctor-patient interactions efficiently. It allows patients to book appointments, access medical records, and communicate with doctors online.

## Problem Statement
Traditional hospital systems rely on manual processes, leading to long queues, inefficient scheduling, and difficulty in managing patient records.

## Objectives
- Provide online appointment booking
- Enable easy access to medical records
- Improve communication between doctors and patients
- Reduce workload for hospital staff

## Existing System
- Manual appointment booking
- Paper-based records
- Time-consuming processes

## Proposed System
- Online appointment booking
- Digital medical records
- Secure data storage
- Remote access for doctors and patients

## Features
### Patient
- Register & Login
- Book appointments
- View medical records

### Doctor
- Manage appointments
- Access patient records

### Donor
- Organ donation system
- View donation details

## Methodology
- SDLC (System Development Life Cycle)
- User-Centered Design
- Design Science Research

## Results
The system successfully provides an interface for managing appointments and medical data efficiently.

## Conclusion
The portal improves healthcare accessibility and reduces manual workload.

## Future Scope
- Virtual doctor consultation
- Health tracking
- AI-based diagnosis
